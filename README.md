# Employee Department & Project Analysis using SQL

## 📌 Project Overview

This project focuses on analyzing employee, department, project, and timesheet data using SQL. The objective is to understand workforce allocation, employee performance, project participation, salary distribution, and departmental insights through data-driven analysis.

The project demonstrates practical SQL skills including joins, aggregate functions, subqueries, views, window functions, and data manipulation operations.

---

## 🛠️ Technology Used

* MySQL 
* SQL (MySQL Workbench)
* Relational Database Management System (RDBMS)

---

## 📂 Database Structure

The project consists of four tables:

### Employees

Contains employee information such as:

* Employee ID
* First Name
* Last Name
* Job Title
* Department ID
* Salary

### Departments

Contains department details:

* Department ID
* Department Name
* Location

### Projects

Contains project information:

* Project ID
* Project Name

### Timesheets

Stores employee work records:

* Employee ID
* Project ID
* Hours Worked

---

## 🔍 Analysis Performed

### Employee & Department Analysis

* Find the working location of each employee
* Assign salaries based on departments
* Identify the department with the highest average salary
* Classify employees based on job roles
* Update job titles for engineering employees

### Project Analysis

* Find projects assigned to employees
* Identify employees working on multiple projects
* Determine the project with the highest total hours
* Analyze employee participation across projects

### Timesheet Analysis

* Calculate total hours worked by employees
* Calculate total hours worked on each project
* Identify employees working more than 20 hours on a single project
* Rank employees based on total working hours
* Find employees whose working hours are above average

### Workforce Analysis

* Identify employees not assigned to any project
* Analyze department-wise employee distribution
* Evaluate employee workload and productivity
