
# Employee Database SQL Question Set

## Questions

1. Find the working location of each employee.

2. Create a Salary column and update salaries for each department.

3. Find which project each employee is working on.

4. Find the total hours worked on each project by each employee.

5. Find employees who have not worked on any project.

6. Find the project with the maximum hours worked.

7. Create a view storing employees' department names and salaries.

8. Create a view storing projects allocated to each employee.

9. Find employees who worked more than 20 hours on a single project.

10. Classify employees as Manager, Developer, or Other based on job title.

11. Retrieve employees who worked on multiple projects.

12. Rank employees based on total hours worked.

13. Find employees whose total hours worked are above the overall average.

14. Update Engineering employees to 'Senior Developer' except Managers and HR Specialists.

15. Find the department with the highest average salary.

---

- SELECT
- JOINs
- Aggregate Functions
- GROUP BY
- HAVING
- CASE Statements
- Subqueries
- Views
- Window Functions
- UPDATE Statements
